Privacy policy

Last updated: 26 October 2026

"dark psych uploader" (on Pinterest: "Dark Psych Notes Poster") is a private tool run by dark.psych.notes. It is used only to post our own videos and images to our own YouTube channel and our own Pinterest account. It has a single user: the owner of dark.psych.notes. Nobody else can sign in to it.

YouTube

With the owner's permission, the tool uses Google's YouTube Data API with the youtube.upload permission to upload videos and set their title and description. It doesn't read, collect or store data about any other user, and it doesn't sell or share data with anyone.

The login token is kept as an encrypted secret in our private GitHub repository. You can revoke the tool's access at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. YouTube uploads are also covered by the YouTube Terms of Service and the Google Privacy Policy.

Pinterest

With the owner's permission, the tool uses the Pinterest API to create Pins and boards on the owner's own Pinterest account. It asks for these permissions: boards:read and boards:write (to find or create our own boards), pins:read and pins:write (to create our own Pins and check them), and user_accounts:read (to show which account is connected).

The only Pinterest data the tool keeps is the IDs and links of the boards and Pins it created, so it doesn't post the same thing twice. It doesn't read, collect or store data about any other Pinterest user, and it doesn't sell or share any Pinterest data.

The app's ID and secret are kept as encrypted secrets in our private GitHub repository. Access tokens are requested fresh each time the tool runs, used only during that run and never saved. The owner can remove the tool's access at any time in Pinterest's settings, in the list of apps that have access to the account. Use of Pinterest is also covered by the Pinterest Privacy Policy.
