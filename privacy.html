Privacy policy

Last updated: 19 October 2026

"dark psych uploader" is a private tool run by dark.psych.notes. It is used only to upload our own videos to our own YouTube channel.

What data it uses

With the owner's permission, the tool uses Google's YouTube Data API with the youtube.upload permission to upload videos and set their title and description. It doesn't read, collect or store data about any other user, and it doesn't sell or share data with anyone.

How the login is stored

The login token is kept as an encrypted secret in our private GitHub repository. You can revoke the tool's access at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. YouTube uploads are also covered by the YouTube Terms of Service and the Google Privacy Policy.
